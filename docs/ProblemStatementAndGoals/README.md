# Problem Statement and Goals

The first deliverable: it defines the problem the Troitsky Toolbox addresses and
what the project sets out to achieve. Later documents, starting with the
[SRS](../SRS/), build on it.

**Rendered document:** [ProblemStatement.pdf](https://jackeaston4.github.io/Troitsky-Toolbox/ProblemStatementAndGoals/ProblemStatement.pdf)

## Contents

[ProblemStatement.tex](ProblemStatement.tex) is the whole document:

| Section | What it covers |
|---|---|
| Problem Statement | The problem, inputs and outputs, stakeholders (primary, secondary, tertiary) and the software environment. |
| Goals | Information centralization, model analysis and bridge predictions, material testing support, knowledge transfer, and integrating software development into the club. |
| Stretch Goals | Preparing the project for future development, maintenance and expansion. |
| Custom Documents | The two CDs chosen: interviews (Fall) and usability testing (Winter). See [CDs](../CDs/). |
| Appendix | Team reflection. |

## Building

From the repository root: `make docs/ProblemStatementAndGoals/ProblemStatement.pdf`.
