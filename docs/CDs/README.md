# Custom Documents (CDs)

Each term the team submits one Custom Document (CD), chosen from the course
catalogue.

| Term | CD (as assigned by the course) | Folder | Report | Status |
|---|---|---|---|---|
| **CD-Fall** | User/Stakeholder/Client interview report | [Interviews/](Interviews/) | [InterviewReport.pdf](https://jackeaston4.github.io/Troitsky-Toolbox/CDs/Interviews/InterviewReport.pdf) | Submitted |
| **CD-Winter** | Usability Report | [UsabilityTesting/](UsabilityTesting/) | Not started | Planned |

Further information is provided within the README of each given CD.

The other CD templates shipped with the course template repo were removed,
because the checklists ask that unused template folders be deleted.
