# Verification and Validation Plan

This document outlines how the team will verify and validate that the Troitsky
Toolbox meets the requirements in the [SRS](../SRS/). It focuses verification
on high-risk points and the safety-critical concerns identified in the
[Hazard Analysis](../HazardAnalysis/), and defines the system and unit tests
used to build confidence in the correctness, reliability and safety of the
system.

**Rendered document:** [VnVPlan.pdf](https://jackeaston4.github.io/Troitsky-Toolbox/VnVPlan/VnVPlan.pdf)

## Contents

[VnVPlan.tex](VnVPlan.tex) is the whole document:

| Section | What it covers |
|---|---|
| Symbols, Abbreviations, and Acronyms | Terms used throughout the plan. |
| General Information | A summary of the system, the V&V objectives and what is out of scope, the Custom Documents and the related project documentation. |
| Plan | The V&V team, verification of the SRS, design, V&V plan and implementation, the automated testing tools, and software validation. |
| System Tests | Tests for the functional and non-functional requirements, and the traceability between test cases and requirements. |
| Unit Test Description | Unit testing scope, unit tests for functional and non-functional requirements, and the traceability between test cases and modules. |
| Appendix | Symbolic parameters, the member needs survey, the stakeholder interview guide, the usability test plan and survey, the generative AI disclosure and the team reflection. |

The member needs survey and interview guide summarize material recorded in
full in the [CD-Fall](../CDs/Interviews/) folder, and the usability test plan
supports [CD-Winter](../CDs/UsabilityTesting/). References come from the
shared [refs/References.bib](../../refs/References.bib).
