\nsection{P.2 Imposed technical choices}

\begin{itemize}

\item \textbf{Programming languages:} Primarily done in C\# on .NET

\item \textbf{Front End:} C\# HTML, Razor Pages (Blazor), considering React + Typescript for certain components.

\item \textbf{File Formats:} STEP (.stp) files for loading and submitting models. Standardized format among possible 
external modelling software teams use.

\item \textbf{Testing:} MSTest, NUnit/XUnit, Coverlet for coverage

\item \textbf{Linting/ coding standard:} CS Lint, Standard .NET coding conventions

\item \textbf{Authentification (RBAC):} ASP.NET Core Identity.

\end{itemize}
