\nsection{P.2 Imposed technical choices}

\begin{itemize}

\item \textbf{Platform/delivery:} Web app for desktop browsers. Accessible through traditional browsers 
such as Google Chrome, Firefox, Edge, and Safari. Requires a working internet connection to utilize the service.
\\ \textbf {Rationale:} Ensures that the service is accessible by all club members. Also allows the Troitsky toolbox to act as a 
landing page for the McMaster club.

\item \textbf{File Formats:} STEP (.stp) files for loading and submitting models.
\\ \textbf {Rationale:} Standardized format among possible external modelling software teams use. Ensures compatibility 
with current and future model files.

\item \textbf{Back-end Programming languages:} C\# on .NET, Python for subservices
\\ \textbf {Rationale:} LINQ availability and ease of use, and the ease of maintainability by future software subteam members; Python for
accessibility to beneficial open-source libraries.

\item \textbf{Testing, Linting and Coding Standard:} xUnit/bUnit + Coverlet for coverage, \texttt{dotnet format}, Standard .NET coding conventions
\\ \textbf {Rationale:} xUnit and Coverlet are widely documented; bUnit, running on top of xUnit, supports the 
testing of Blazor components. \texttt{dotnet format} ships with the .NET SDK and can work with config files to integrate with the .NET compiler.

\item \textbf{Authentication (RBAC):} ASP.NET Core Identity.
\\ \textbf {Rationale:} RBAC matches the club structure, and Identity is built into the ASP.NET Core stack.

\end{itemize}
