\nsection{S.3 Interfaces}
\comment{How the system makes the functionality of S.2 available to the rest of the world, particularly user interfaces and program interfaces (APIs).}

This system requires several sofware interfaces, including:

\begin{itemize}
    \item An RESTful API (artificial programming interface), which shall enable users to communicate
    with the backend through the frontend and alter it when permitted and desired.
    \item External static modelling libraries, which shall perform technical engineering calculations
    on given inputs, both on calculations necessary to score STP models and inputs for materials testing.
    \item A robust external server which holds the entire swath of data this toolbox relies on, including
    STP files, material testing inputs, documents containing non-technical club knowledge and roles for user accounts.
    \item Some aid to login. This may be an entire external login service or merely a cryptographic hash function which 
    guards passwords to minimize collateral damage in case of a data leak.
\end{itemize}
