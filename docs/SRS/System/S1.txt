The Troitsky Toolbox is a web-based application composed of a set of largely independent tools that share common account, storage, and presentation infrastructure. The system relies on the following software components:

\begin{itemize}
    \item \textbf{Access Manager:} The component in charge of managing member accounts and their roles (\texttt{Manage Members}), such as general member, executive, and software subteam maintainer. It authenticates users (\texttt{Authenticate}) and enforces role-based access to every other component, ensuring that the public landing page remains generally accessible while club services and stored data are limited to authorized members.

    \item \textbf{Knowledge Repository:} The component in charge of the centralized store of club information (\texttt{Manage Content}), including past bridge designs, documentation, competition results, and other development information. It allows members to search and filter stored content (\texttt{Search Content}) and to contribute new content, growing the repository from year to year.

    \item \textbf{Model Analyzer:} The component in charge of importing bridge models in a standardized 3D format, such as STEP (\texttt{Upload Model}), rendering an interactive visualization of the model, and extracting the geometric and structural data of the bridge (\texttt{Model Data}). The extracted data is provided to the Performance Estimator and the Rule Compliance Checker.

    \item \textbf{Performance Estimator:} The component in charge of computing key metrics and predictions about a bridge's expected performance (\texttt{Estimate Performance}), using the geometry provided by the Model Analyzer (\texttt{Model Data}) and the material properties provided by the Material Testing Manager (\texttt{Material Properties}).

    \item \textbf{Rule Compliance Checker:} The component in charge of assessing a bridge model against the current Troitsky competition rules (\texttt{Check Compliance}), using the data provided by the Model Analyzer (\texttt{Model Data}). It maintains the set of rules being checked (\texttt{Manage Rules}) so that they can be updated as the competition rules change from year to year.

    \item \textbf{Material Testing Manager:} The component in charge of recording material testing results in a standardized format (\texttt{Manage Test Results}), and analyzing new results against those collected in previous years. It provides aggregated material properties (\texttt{Material Properties}) to the Performance Estimator.

    \item \textbf{Knowledge Transfer Manager:} The component in charge of collecting and organizing exit documents, role records, and onboarding material (\texttt{Manage Handoff Documents}), so that the knowledge held by graduating members and executive positions is preserved for future members. Completed handoff documents are published to the Knowledge Repository (\texttt{Manage Content}).
\end{itemize}

Each component persists its data through a shared database, with each component owning and managing its own portion of the stored data through the interfaces listed above. In addition to these components, the system will interact with external components, such as a CAD/geometry library used by the Model Analyzer to read STEP files (see E.2 for details).

Club members interact with the system through the \textbf{Toolbox Web App}, a browser-based interface that presents each of the tools above. Through it, members can browse and contribute to the repository, upload and analyze bridge models, record material tests, and complete handoff documents. Members of the software subteam use the same interface, with elevated privileges granted by the Access Manager, to maintain accounts, competition rules, and stored content.
