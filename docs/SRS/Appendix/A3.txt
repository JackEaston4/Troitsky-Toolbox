\subsection*{A.3.2 How and Where Used}
\addcontentsline{toc}{subsection}{A.3.2 How and Where Used}

AI tools were used during this deliverable to assist with the following:
\begin{itemize}
  \item \textbf{Formatting:} help with LaTeX formatting, building, and layout (tables,
  lists, and section structure) across the document.
  \item \textbf{Linking:} adding and fixing internal references and labels
  between sections and requirements within the SRS.
  \item \textbf{Review:} reviewing drafted sections for clarity, consistency,
  and possible errors or omissions.
  \item \textbf{Cross-referencing between documents:} updating and checking
  references between the SRS and the Hazard Analysis, so that the functional
  and non-functional requirements cited in the Hazard Analysis FMEA table
  match the current SRS.
\end{itemize}

\subsection*{A.3.3 Verification of AI-Generated Content}
\addcontentsline{toc}{subsection}{A.3.3 Verification of AI-Generated Content}

The team followed the same policy for AI use that the Development Plan sets
for AI-generated code: each developer shall thoroughly review all
AI-generated content before creating a pull request and not submit the
content for a pull request until they completely understand it and are
convinced of its validity.

\begin{itemize}
  \item Each team member reviewed any AI-assisted changes to their own
  sections before opening a pull request.
  \item Cross-references between the SRS and the Hazard Analysis were checked
  by hand against the current version of both documents.
  \item Pull requests were reviewed by at least one other team member before merging.
  \item The team is responsible for the accuracy, completeness, consistency,
  and appropriateness of this document, whether material was written by a
  person or with help from an AI tool.
\end{itemize}
