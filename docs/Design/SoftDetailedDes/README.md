# Module Interface Specification (MIS)

The Module Interface Specification gives the interface of each module in the
[Module Guide](../SoftArchitecture/): the access programs it exports, their
inputs, outputs and exceptions, and the state and behaviour behind them. It
uses the same module names, numbering (M1 to M20) and uses hierarchy as the
Module Guide.

**Rendered document:** [MIS.pdf](https://jackeaston4.github.io/Troitsky-Toolbox/Design/SoftDetailedDes/MIS.pdf)

## Contents

[MIS.tex](MIS.tex) is the whole document:

| Section | What it covers |
|---|---|
| Symbols, Abbreviations and Acronyms | Terms used throughout the document. |
| Introduction | An overview of the Toolbox's services and the complementary documents. |
| Notation | The mathematical notation and the derived types shared across modules. |
| Module Decomposition | The module hierarchy, taken from the Module Guide. |
| MIS of each module | One section per module (M1 to M20), each with its Module, Uses, Syntax and Semantics. |
| Appendix | The generative AI disclosure and the team reflection. |
