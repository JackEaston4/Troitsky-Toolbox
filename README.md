# Troitsky Toolbox

Developer Names: Pedro Azevedo, Mason Azzopardi, Michael Roberts, Jack Easton

Date of project start: September 2026

The McMaster Troitsky club is a student-run organization that registers and
supports 4-6 teams of students as they take on the task of modelling, ana-
lyzing and manufacturing a bridge out of popsicle sticks, white glue and dental
floss. This project seeks to create a centralized information repository and technical
support system for the McMaster Troitsky club, ensuring information trans-
fer between years and teams, and facilitating support and onboarding for new
members. 

The project is designed to be maintained long-term by a software subteam within the club.

The folders and files for this project are as follows:

docs - Documentation for the project
refs - Reference material used for the project, including papers
src - Source code
test - Test cases
